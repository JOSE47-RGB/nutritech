# Consulta guiada para familias

La consulta temporal compartida por usuario normal y administración muestra tres pasos: datos del niño, medidas y revisión antes del cálculo. Los campos de pasos inactivos quedan ocultos y deshabilitados; el envío reúne el borrador con el paso activo. Atrás conserva la información. Las validaciones nativas se aplican al paso activo y las fechas se comprueban antes de avanzar. La ayuda extensa sobre edema queda desplegable, manteniendo desconocido como valor inicial.
